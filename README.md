This project presents a statistical and machine learning-based analysis of heart attack risk using a real-world healthcare dataset. The study includes data preprocessing, exploratory data analysis (EDA), correlation analysis, feature selection, and predictive modeling using Logistic Regression and Random Forest algorithms. Various health and lifestyle factors such as age, cholesterol, smoking, diabetes, obesity, exercise habits, and sleep patterns were analyzed to identify their impact on heart attack risk. The project aims to provide insights into cardiovascular risk prediction and demonstrates the application of data science techniques in healthcare analytics.
